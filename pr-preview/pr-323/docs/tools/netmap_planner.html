Netmap planner

When two sites joined by a VPN use the same network, enter each site's real and mapped network and the planner gives you the VPN and NETMAP settings for both firewalls. See Netmap for how the rules work.

Test with two example hosts

From 192.168.1.10 (site A), to reach 192.168.1.20 (site B): ping 10.2.2.20

From 192.168.1.20 (site B), to reach 192.168.1.10 (site A): ping 10.1.1.10

Site B sees the connection coming from 10.1.1.10. Use that address in firewall rules and look for it in the logs.

Good to know
  • Firewall rules between the two sites use the other site's mapped network.
  • The mapped networks must not exist at either site or in any other VPN.
  • A DNS name that resolves to a host's real IP at the other site won't work. Use the mapped address instead.
