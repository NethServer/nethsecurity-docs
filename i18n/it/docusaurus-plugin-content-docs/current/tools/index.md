# Strumenti

Strumenti interattivi per pianificare una configurazione di NethSecurity prima di applicarla.

- [Pianificatore Netmap](./netmap_planner.mdx) — due sedi con la stessa rete collegate in VPN: inserisci le reti, ottieni le configurazioni
- [Pianificatore alta affidabilità](./ha_planner.mdx) — pianifica gli indirizzi del cluster, ottieni i comandi `ns-ha-config`
