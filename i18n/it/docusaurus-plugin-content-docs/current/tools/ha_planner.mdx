# Pianificatore alta affidabilità

Inserisci gli indirizzi dell'interfaccia HA e delle eventuali interfacce LAN aggiuntive o IP virtuali, e il pianificatore ti dà i comandi `ns-ha-config` per configurare il cluster. Vedi [Configurazione e gestione](../administrator-manual/high-availability/ha_setup_and_management.md) per il funzionamento del cluster.
