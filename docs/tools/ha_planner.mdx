# High availability planner

Enter the addresses of the HA interface and of any additional LAN interface or virtual IP, and the planner gives you the `ns-ha-config` commands to set up the cluster. See [Setup and management](../administrator-manual/high-availability/ha_setup_and_management.md) for how the cluster works.
